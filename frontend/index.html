Connect your own infrastructure, pick a risk profile, deploy.

How "connect wallet" actually works here: this page never asks for a private key or seed phrase, and there is no server run by this project that your wallet or funds ever touch. You run your own Hummingbot Gateway + API instance, import your wallet into it (encrypted locally, on your machine) — see docs/wallet-setup.md — and this page only talks to your own API URL, directly from your browser, to register and deploy the controller config below.

1 · Your Hummingbot API

Stored only in this browser's localStorage, on this device. Sent only to the API URL above when you click a button on this page — never anywhere else.

2 · Your wallet

For display/verification only — this page doesn't use it to sign anything. Your Gateway instance signs using the key you imported directly into it.

3 · Risk profile

4 · Pool

Automatic pool discovery (on-chain + narrative funnel) runs server-side via routines/narrative_lp_funnel.py — this page deploys against one pool you specify directly. Paste a pool that already cleared the funnel (or one you've chosen manually).
